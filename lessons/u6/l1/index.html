The Missing Dollar

Three friends pay $30 for a hotel room, $10 each. It really costs $25, so the bellhop brings back $5: he gives each friend $1 and keeps $2.

Each paid $9: 3\times\$9=\$27, and \$27+\$2=\$29.

Where did the missing dollar go?

?
Follow the money. Where is every dollar?
No dollar is missing! Adding the bellhop’s $2 to the $27 is the trick: that $2 is already inside the $27. The friends paid $27 in total: \$25 to the hotel +\ \$2 to the bellhop. The right sum adds the money they got back: \$27+\$3=\$30. (Every dollar: $25 hotel, $2 bellhop, $3 back in their pockets.)

Rational Expressions and Non-Permissible Values

A rational expression is a fraction made of polynomials. It works like any fraction, except where its denominator is 0: those values of the variable are its non-permissible values, and the expression has no value there.

I can…
  • tell whether an expression is a rational expression, and evaluate one
  • explain why division by zero is undefined, using multiplication and a table of values
  • find the non-permissible values (NPVs), factoring the denominator first, including in terms of y
  • see why two expressions with the same values can have different restrictions
  • build an expression with given NPVs, and use NPVs in a context

Today: what a rational expression is, evaluating it, and its non-permissible values.
1

What Is a Rational Expression?

A rational number is a quotient \dfrac{p}{q} of two integers with q\ne0. In the same way, a rational expression is a quotient \dfrac{P}{Q} of two polynomials, where Q\ne0. A polynomial has only whole-number exponents on its variables: no variable under a radical, in an exponent or in a denominator. A polynomial by itself, such as x^2-4x+1, is also a rational expression (its denominator is 1).

Rational expression: \dfrac{\textcolor{#12805a}{\text{polynomial}}}{\textcolor{#1f5bd6}{\text{polynomial}}}, the denominator not 0.   Examples: \dfrac{5}{x},  \dfrac{x+3}{x^2-4},  \dfrac{2a^2-1}{7}.

To evaluate a rational expression, substitute the value and simplify the numerator and the denominator separately. A numerator of 0 is fine (the value is 0); a denominator of 0 makes the expression undefined.

Example 1

Rational or not?

Is each a rational expression? Explain.

(a) \dfrac{x^2-5}{3x}
Yes: both parts are polynomials.
(b) \dfrac{4}{\sqrt{x}+1}
No: \sqrt{x} is not a polynomial term.
(c) \dfrac{2y+7}{9}
Yes: a polynomial over the polynomial 9.
(d) \dfrac{x}{x^2+1}
Yes: both parts are polynomials.
Example 2

Evaluate

Evaluate \dfrac{x^2-4x}{2x+6} for each value of x.

(a) x=5
\dfrac{25-20}{10+6}=\boldsymbol{\dfrac{5}{16}}
(b) x=-1
\dfrac{1+4}{-2+6}=\boldsymbol{\dfrac{5}{4}}
(c) x=4
\dfrac{16-16}{8+6}=\dfrac{0}{14}=\boldsymbol{0}
(d) x=-3
\dfrac{9+12}{-6+6}=\dfrac{21}{0}: undefined
2

Why Division by Zero Is Undefined

Division undoes multiplication: \dfrac{12}{3}=4 because 4\times3=12. If \dfrac{12}{0} had a value k, then k\times0 would be 12, but k\times0=0 for every k. So \dfrac{12}{0} has no value. (\dfrac{0}{0} fails too: every k works, so there is no single value.)

A table of values shows what happens near a value that makes a denominator 0: the expression grows without bound and changes sign, so no number fits there. On a calculator, enter the expression as Y1 and look at its TABLE: it shows ERROR at that value.

Non-Permissible Values

A non-permissible value (NPV) is a value of the variable that makes a denominator equal 0. These values are the restrictions on the variable. Only the denominator matters: a numerator equal to 0 is allowed.

To find the NPVs: set each denominator (each factor with a variable) equal to 0 and solve. Write them as x\ne3, or x\ne-2,\ 5, or x\ne\pm4.

A denominator with no variable, such as 8, gives no NPV. A denominator like x^2+16 is never 0 (a square is never negative, so x^2+16\ge16), so it gives no NPV either.

Example 4

Monomial and binomial denominators

Determine the non-permissible values.

(a) \dfrac{9}{5x}
5x=0
\boldsymbol{x\ne0}
(b) \dfrac{2y-1}{y+8}
y+8=0
\boldsymbol{y\ne-8}
(c) \dfrac{m^2+4}{12-3m}
12-3m=0\Rightarrow m=4
\boldsymbol{m\ne4}
(d) \dfrac{x}{7x+2}
7x+2=0\Rightarrow x=-\frac{2}{7}
\boldsymbol{x\ne-\frac{2}{7}}
(e) \dfrac{4k+3}{10}
The denominator 10 is never 0: no NPVs.
(f) \dfrac{3x}{x^2+16}
x^2+16\ge16, never 0: no NPVs.
4

Factor the Denominator First

When a denominator is a trinomial, a difference of squares or has a common factor, factor it fully (Unit 4) and use the zero product property: each factor with a variable gives an NPV. Ignore the numerator, even if it shares a factor with the denominator. In an expression with more than one fraction, every denominator gives NPVs. With two variables, solve for the variable asked for (for example, x in terms of y).

Example 5

Factor, then find the NPVs

Determine the non-permissible values.

(a) \dfrac{x-4}{x^2+2x-15}
(x+5)(x-3)=0
\boldsymbol{x\ne-5,\ 3}
(b) \dfrac{8}{x^2-36}
(x-6)(x+6)=0
\boldsymbol{x\ne\pm6}
(c) \dfrac{n+2}{3n^2-12n}
3n(n-4)=0
\boldsymbol{n\ne0,\ 4}
(d) \dfrac{1}{2x^2+7x-4}
ac=-8: 8 and -1
(2x-1)(x+4)=0
\boldsymbol{x\ne\frac{1}{2},\ -4}
(e) \dfrac{y+3}{y^2-10y+25}
(y-5)^2=0
\boldsymbol{y\ne5}
(f) \dfrac{5}{x^3-9x}
x(x^2-9)=x(x-3)(x+3)=0
\boldsymbol{x\ne0,\ \pm3}
Example 6

Two variables, two fractions

Determine the non-permissible values (in (b), for x in terms of y).

(a) \dfrac{5}{3a^2b}
3a^2b=0 when a=0 or b=0.
\boldsymbol{a\ne0,\ b\ne0}
(b) \dfrac{x+y}{x^2-25y^2}
(x-5y)(x+5y)=0
\boldsymbol{x\ne\pm5y}
(c) \dfrac{x}{x-1}+\dfrac{2}{x^2+4x}
x-1=0 and x(x+4)=0
\boldsymbol{x\ne1,\ 0,\ -4}

Same Values, Different Restrictions

Two rational expressions can give the same value for almost every x but have different NPVs. This is the idea behind simplifying (Lesson 2): the restrictions of the original expression must be kept.

Example 7

(b) For which value of x do the expressions differ?
At \boldsymbol{x=-2}: the first is \frac{0}{0} (undefined), the second is 3. Everywhere else they are equal.
(c) State the NPVs of each expression.
x^2+5x+6=(x+2)(x+3), so the first has \boldsymbol{x\ne-2,\ -3}. The second has only \boldsymbol{x\ne-3}.
6

Building Expressions and Using Them in Context

To build an expression with given NPVs, work backwards as in Unit 4: an NPV x=r comes from a factor (x-r) in the denominator, and x=\frac{p}{q} from (qx-p). In a context, the NPVs are values the variable can never take, and the situation often restricts the variable further (a length or a speed must be positive, a count must be a whole number).

Example 8

Build it backwards

Write a rational expression with a numerator of 1 and the denominator expanded that has the given NPVs.

(a) x\ne-1,\ 6
\dfrac{1}{(x+1)(x-6)}=\boldsymbol{\dfrac{1}{x^2-5x-6}}
(b) x\ne0,\ \frac{2}{3}
\dfrac{1}{x(3x-2)}=\boldsymbol{\dfrac{1}{3x^2-2x}}
(c) x\ne\pm4
\dfrac{1}{(x-4)(x+4)}=\boldsymbol{\dfrac{1}{x^2-16}}
(d) no NPVs
For example \boldsymbol{\dfrac{1}{x^2+1}} (x^2+1\ge1)
(e) The expression \dfrac{1}{x^2+kx-12} has an NPV of x=2. Determine k and the other NPV.
x=2 makes the denominator 0: 4+2k-12=0, so \boldsymbol{k=4}.
x^2+4x-12=(x+6)(x-2). The other NPV is \boldsymbol{x=-6}.
Example 9

Up the river

A boat travels 36 km up a river against a current of 3 km/h. If its speed in still water is v km/h, its speed upstream is (v-3) km/h and the trip takes t=\dfrac{36}{v-3} hours.

(a) Determine the time for v=15 and for v=12.
v=15: t=\frac{36}{12}= 3 h
v=12: t=\frac{36}{9}= 4 h
(b) State the NPV. What would it mean for the boat?
\boldsymbol{v\ne3}. At v=3 the boat moves upstream at 0 km/h: it never arrives, so there is no time.
(c) Which values of v make sense here?
\boldsymbol{v>3}. For v<3 the time is negative: the current carries the boat backwards.

Key ideas

Rational expression. \dfrac{\text{polynomial}}{\text{polynomial}}, the denominator not 0. To evaluate, simplify the numerator and the denominator separately. A 0 on top is fine; a 0 underneath is undefined.
Why ÷ 0 fails. \frac{12}{0}=k would need k\times0=12: impossible. Near an NPV the values grow without bound and change sign; the calculator TABLE shows ERROR.
NPVs. Factor every denominator fully, set each factor with a variable equal to 0, and solve. Ignore the numerator. Write x\ne-5,\ 3. A denominator like x^2+16 gives none.
Backwards and in context. x\ne r comes from (x-r), x\ne\frac{p}{q} from (qx-p). Keep the original NPVs. A context often allows even fewer values (v>3).
