Exact Values from Special Triangles

Most trig ratios are long decimals, but 30°, 45° and 60° have exact values. They come from two triangles you can cut from a square and an equilateral triangle. With reference angles and CAST they give exact answers in every quadrant. A calculator only gives decimals: today every answer is exact.

I can…
  • build the 45-45-90 triangle (1,\ 1,\ \sqrt{2}) and the 30-60-90 triangle (1,\ \sqrt{3},\ 2) from memory
  • write the table of exact values for 0^\circ,\ 30^\circ,\ 45^\circ,\ 60^\circ,\ 90^\circ in rationalized form
  • find the exact value of a ratio of any angle from 0^\circ to 360^\circ with the reference angle and CAST
  • evaluate exact expressions such as \sin^2 60^\circ+\cos 180^\circ
  • solve equations such as 2\sin\theta+1=0 exactly, without a calculator
  • find an exact angle from a point on the terminal arm or from a ratio and a quadrant

1

The Two Special Triangles

Most ratios are irrational decimals, but the angles 30^\circ, 45^\circ and 60^\circ have exact values that come from two triangles.

Cut a square
Cut a square with side 1 along a diagonal: each half is a right isosceles triangle with angles 45^\circ,\ 45^\circ,\ 90^\circ.
Cut an equilateral triangle
Cut an equilateral triangle with side 2 by an altitude: each half has angles 30^\circ,\ 60^\circ,\ 90^\circ, hypotenuse 2 and shortest side 1.
A calculator only gives decimals, so it can check an answer here, but every answer in this lesson is exact. Write a radical denominator in rationalized form, as in Unit 2: \dfrac{1}{\sqrt{2}}=\dfrac{\sqrt{2}}{2} and \dfrac{1}{\sqrt{3}}=\dfrac{\sqrt{3}}{3}.
Example 1

Build the special triangles

(a) The square has side 1. Find the diagonal d, then the ratios of 45^\circ.
d^2=1^2+1^2=2, so d=\sqrt{2}.
\sin 45^\circ=\dfrac{1}{\sqrt{2}}=\dfrac{\sqrt{2}}{2},\quad \cos 45^\circ=\dfrac{1}{\sqrt{2}}=\dfrac{\sqrt{2}}{2}
\tan 45^\circ=\dfrac{1}{1}=1
(b) The equilateral triangle has side 2. Find the altitude h, then the ratios of 30^\circ and 60^\circ.
h^2=2^2-1^2=3, so h=\sqrt{3}. Sides: 1 (opposite 30^\circ), \sqrt{3} (opposite 60^\circ), 2.
\sin 30^\circ=\dfrac{1}{2},\ \cos 30^\circ=\dfrac{\sqrt{3}}{2},\ \tan 30^\circ=\dfrac{1}{\sqrt{3}}=\dfrac{\sqrt{3}}{3}
\sin 60^\circ=\dfrac{\sqrt{3}}{2},\ \cos 60^\circ=\dfrac{1}{2},\ \tan 60^\circ=\dfrac{\sqrt{3}}{1}=\sqrt{3}
!
Which side is which? The hypotenuse is always the longest side: \sqrt{2} in the first triangle, 2 in the second. In the 30-60-90 triangle the shortest side (1) is opposite the smallest angle (30^\circ), and \sqrt{3} is opposite 60^\circ.
2

The Table of Exact Values

For 0^\circ and 90^\circ use the points (1,\ 0) and (0,\ 1) with r=1 (Lesson 2). The values for 0^\circ to 90^\circ go in one table that you should know from memory.

Patterns to help you remember:
  • The sines from 0^\circ to 90^\circ are \dfrac{\sqrt{0}}{2},\ \dfrac{\sqrt{1}}{2},\ \dfrac{\sqrt{2}}{2},\ \dfrac{\sqrt{3}}{2},\ \dfrac{\sqrt{4}}{2}: they increase from 0 to 1.
  • The cosines are the same list in reverse: they decrease from 1 to 0.
  • \tan\theta=\dfrac{\sin\theta}{\cos\theta} (since \dfrac{y/r}{x/r}=\dfrac{y}{x}), and \tan 90^\circ is undefined because \cos 90^\circ=0.

Where the values come from: shrink each triangle so its hypotenuse is 1, and its corner lands on a circle of radius 1 at the point (\cos\theta,\ \sin\theta).

Example 2

The table of exact values

Complete the table of exact values. Write each value in rationalized form.

\theta0^\circ30^\circ45^\circ60^\circ90^\circ
\sin\theta0\dfrac{1}{2}\dfrac{\sqrt{2}}{2}\dfrac{\sqrt{3}}{2}1
\cos\theta1\dfrac{\sqrt{3}}{2}\dfrac{\sqrt{2}}{2}\dfrac{1}{2}0
\tan\theta0\dfrac{\sqrt{3}}{3}1\sqrt{3}undefined
Sines 0,\ \tfrac12,\ \tfrac{\sqrt2}{2},\ \tfrac{\sqrt3}{2},\ 1; cosines the same list backwards; tangents 0,\ \tfrac{\sqrt3}{3},\ 1,\ \sqrt3, undefined. (Tap a cell to check one value at a time.)
3

Exact Values in Any Quadrant

Exact value of a ratio of \theta: (1) find the quadrant and the reference angle \theta_R; (2) if \theta_R is 30^\circ, 45^\circ or 60^\circ, take the value from the table; (3) attach the sign from CAST. For a quadrantal angle use x, y and r=1 directly.
Example 3

Exact values in any quadrant

Determine the exact value.

(a) \sin 240^\circ
Quadrant III, \theta_R=60^\circ, sin negative.
\sin 240^\circ=-\sin 60^\circ=\boldsymbol{-\dfrac{\sqrt{3}}{2}}
(b) \cos 135^\circ
Quadrant II, \theta_R=45^\circ, cos negative.
\cos 135^\circ=-\cos 45^\circ=\boldsymbol{-\dfrac{\sqrt{2}}{2}}
(c) \tan 330^\circ
Quadrant IV, \theta_R=30^\circ, tan negative.
\tan 330^\circ=-\tan 30^\circ=\boldsymbol{-\dfrac{\sqrt{3}}{3}}
(d) \cos 225^\circ
Quadrant III, \theta_R=45^\circ, cos negative.
\cos 225^\circ=\boldsymbol{-\dfrac{\sqrt{2}}{2}}
(e) \sin 180^\circ
Point (-1,\ 0), r=1.
\sin 180^\circ=\dfrac{0}{1}=\boldsymbol{0}
(f) \tan 270^\circ
Point (0,\ -1): \tan 270^\circ=\dfrac{-1}{0}, which is undefined.
!
The reference angle goes to the x-axis, never the y-axis: \theta_R=180^\circ-\theta (II), \theta-180^\circ (III), 360^\circ-\theta (IV). Find the size from the table first, then put the sign in front.
4

Exact Expressions

Replace each ratio by its exact value in brackets, then simplify with the order of operations. The notation \sin^2\theta means (\sin\theta)^2: find \sin\theta first, then square it.
Example 4

Exact expressions

Determine the exact value of each expression.

(a) \sin^2 60^\circ+\cos 180^\circ
=\left(\dfrac{\sqrt{3}}{2}\right)^2+(-1)=\dfrac{3}{4}-1=\boldsymbol{-\dfrac{1}{4}}
(b) 2\cos 45^\circ\sin 135^\circ
=2\left(\dfrac{\sqrt{2}}{2}\right)\left(\dfrac{\sqrt{2}}{2}\right)=\dfrac{2\cdot2}{4}=\boldsymbol{1}
(c) \dfrac{\tan 150^\circ}{1+\tan^2 210^\circ}
\tan 150^\circ=-\dfrac{\sqrt{3}}{3}, \tan 210^\circ=\dfrac{\sqrt{3}}{3}, so \tan^2 210^\circ=\dfrac{3}{9}=\dfrac{1}{3}.
=\dfrac{-\frac{\sqrt{3}}{3}}{\frac{4}{3}}=-\dfrac{\sqrt{3}}{3}\cdot\dfrac{3}{4}=\boldsymbol{-\dfrac{\sqrt{3}}{4}}
(d) Is \sin 60^\circ=2\sin 30^\circ? Explain.
\sin 60^\circ=\dfrac{\sqrt{3}}{2}\approx0.87 but 2\sin 30^\circ=2\left(\dfrac{1}{2}\right)=1.
No: doubling the angle does not double the sine.
!
Brackets first, then the square. \sin^2 60^\circ=\left(\tfrac{\sqrt{3}}{2}\right)^2=\tfrac{3}{4}. It is not \sin(60^2), and \left(\tfrac{\sqrt{3}}{2}\right)^2 squares the top and the bottom.

5

Solving Equations Exactly

To solve \sin\theta=a, \cos\theta=a or \tan\theta=a exactly, use the same steps as in Lesson 3, but read the reference angle from the table instead of the inverse key.

1 Isolate the ratio; rationalize a if needed.
2 Use the sign of a and CAST to choose the quadrants.
3 Find the angle in the table whose ratio is |a|: that is \theta_R.
4 Place \theta_R in each quadrant.
If a is 0, 1, -1 or the ratio is undefined, the answers are quadrantal angles.

If the equation has a square, such as \tan^2\theta=1, take the square root of both sides: \tan\theta=\pm1. Then both signs give solutions, so there can be four.

Example 5

Solve without a calculator

Solve for \theta, 0^\circ\le\theta<360^\circ, without a calculator.

(a) \sin\theta=-\dfrac{\sqrt{3}}{2}
Negative sin: III, IV.
\sin\theta_R=\dfrac{\sqrt{3}}{2}, so \theta_R=60^\circ.
\boldsymbol{\theta=240^\circ} or \boldsymbol{300^\circ}
(b) \cos\theta=-\dfrac{1}{\sqrt{2}}
-\dfrac{1}{\sqrt{2}}=-\dfrac{\sqrt{2}}{2}. Negative cos: II, III.
\theta_R=45^\circ.
\boldsymbol{\theta=135^\circ} or \boldsymbol{225^\circ}
(c) \tan\theta=\sqrt{3}
Positive tan: I, III.
\theta_R=60^\circ.
\boldsymbol{\theta=60^\circ} or \boldsymbol{240^\circ}
Example 6

Isolate first, then solve

Solve, without a calculator.

(a) 2\sin\theta+1=0, 0^\circ\le\theta<360^\circ
\sin\theta=-\dfrac{1}{2}. III, IV; \theta_R=30^\circ.
\boldsymbol{\theta=210^\circ} or \boldsymbol{330^\circ}
(b) \sqrt{3}\tan\theta+1=0, 0^\circ\le\theta\le180^\circ
\tan\theta=-\dfrac{1}{\sqrt{3}}=-\dfrac{\sqrt{3}}{3}. II, IV; \theta_R=30^\circ.
150^\circ or 330^\circ; in the interval only \boldsymbol{\theta=150^\circ}.
(c) \tan^2\theta=1, 0^\circ\le\theta<360^\circ
\tan\theta=1 or \tan\theta=-1; \theta_R=45^\circ.
\tan\theta=1: \boldsymbol{45^\circ,\ 225^\circ}.
\tan\theta=-1: \boldsymbol{135^\circ,\ 315^\circ}.
!
Check the interval. In (b) the interval stops at 180^\circ, so the Quadrant IV answer is thrown out. And a square gives both signs: \tan^2\theta=1 has four answers, not two.
6

Finding an Exact Angle from a Point or a Ratio

If a point on the terminal arm gives a ratio from the table, the angle can be found exactly: find \tan\theta=\dfrac{y}{x} (or r and then sine or cosine), match the reference angle, and place it in the quadrant of the point.

Look for a special triangle in disguise: sides in the ratio 1:1:\sqrt{2} or 1:\sqrt{3}:2, just scaled up.

Example 7

Exact angles

(a) The point P(2\sqrt{3},\ -2) is on the terminal arm of \theta. Determine \theta exactly, 0^\circ\le\theta<360^\circ.
Quadrant IV. \tan\theta=\dfrac{-2}{2\sqrt{3}}=-\dfrac{1}{\sqrt{3}}, so \theta_R=30^\circ.
\theta=360^\circ-30^\circ=\boldsymbol{330^\circ}
(b) The point Q(-3,\ -3\sqrt{3}) is on the terminal arm of \theta. Determine \theta and r.
Quadrant III. \tan\theta=\dfrac{-3\sqrt{3}}{-3}=\sqrt{3}, so \theta_R=60^\circ and \boldsymbol{\theta=240^\circ}.
r=\sqrt{9+27}=\sqrt{36}=\boldsymbol{6}
(c) \sin A=\dfrac{1}{2} and A is not in Quadrant I. Determine A, 0^\circ\le A<360^\circ, and the exact values of \cos A and \tan A.
Positive sin: I or II, so Quadrant II. \theta_R=30^\circ, \boldsymbol{A=150^\circ}.
\cos A=-\cos 30^\circ=\boldsymbol{-\dfrac{\sqrt{3}}{2}}
\tan A=-\tan 30^\circ=\boldsymbol{-\dfrac{\sqrt{3}}{3}}
(d) A terminal arm rotates counterclockwise from the arm through (-1,\ 1) to the arm through (1,\ -\sqrt{3}). Through what angle does it rotate?
(-1,\ 1): Quadrant II, \tan=-1, \theta_R=45^\circ, angle 135^\circ.
(1,\ -\sqrt{3}): Quadrant IV, \tan=-\sqrt{3}, \theta_R=60^\circ, angle 300^\circ.
Rotation: 300^\circ-135^\circ=\boldsymbol{165^\circ}
✓

Key ideas

Two triangles. Half a square: 45^\circ,45^\circ,90^\circ with sides 1,\ 1,\ \sqrt{2}. Half an equilateral triangle: 30^\circ,60^\circ,90^\circ with sides 1,\ \sqrt{3},\ 2 (1 opposite 30^\circ).
The table. Sines \tfrac{\sqrt0}{2},\tfrac{\sqrt1}{2},\tfrac{\sqrt2}{2},\tfrac{\sqrt3}{2},\tfrac{\sqrt4}{2}; cosines the same list reversed; \tan\theta=\tfrac{\sin\theta}{\cos\theta}, undefined at 90^\circ. Rationalize: \tfrac{1}{\sqrt2}=\tfrac{\sqrt2}{2}, \tfrac{1}{\sqrt3}=\tfrac{\sqrt3}{3}.
Any quadrant. Quadrant and \theta_R, the size from the table, the sign from CAST. Quadrantal angles: use (\pm1,0) or (0,\pm1) with r=1. Expressions: values in brackets, \sin^2\theta=(\sin\theta)^2.
Solving exactly. Isolate, rationalize, choose the quadrants by the sign, read \theta_R from the table backwards, place it in each quadrant. A square gives \pm: up to four answers. Check the interval.
