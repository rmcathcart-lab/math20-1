Absolute Value as a Distance from Zero

The absolute value of a real number a, written |a|, is the distance from a to 0 on a number line. A distance is never negative, so |a|\ge0 for every real number. A number and its opposite are the same distance from 0, so they have the same absolute value: |5|=5 and |-5|=5.

Squaring a number removes its sign, and the principal square root is never negative, so the absolute value can also be found as \sqrt{a^2}. For example, \sqrt{(-7)^2}=\sqrt{49}=7=|-7|.

Absolute value: |a| is the distance from a to 0.   |a|\ge0   |-a|=|a|   |a|=\sqrt{a^2}

The bars act only on what is inside them. In -|6| the negative sign is outside the bars, so -|6|=-6; in |-6| it is inside, so |-6|=6.

Evaluating Expressions with Absolute Value

Absolute value bars are grouping symbols, like brackets: simplify the expression inside the bars first, then take its absolute value, then finish with the usual order of operations. The bars cannot be split over a sum or difference, so |a+b| and |a|+|b| are usually different. They can be split over a product or a quotient.

Order of operations: (1) simplify inside the bars;  (2) take the absolute value;  (3) finish: powers, then \times and \div, then + and -.
|ab|=|a|\,|b|  and  \left|\dfrac{a}{b}\right|=\dfrac{|a|}{|b|},  but in general |a+b|\ne|a|+|b| and |a-b|\ne|a|-|b|.
Absolute value on the calculator. On the TI-84 Plus CE, abs( is in the MATH menu under NUM (MATH►1). Type |4-13| as abs(4−13)ENTER. Close the bracket where the bars close.

Comparing and Ordering

To compare or order expressions that contain absolute values, evaluate each one first (a decimal approximation is fine for ordering), then compare the values. To show that a statement is false, one counterexample (a set of values that makes it false) is enough.

Example 4

Least to greatest

Arrange in order from least to greatest.   |-3.6|,\quad -|4|,\quad |2-7|,\quad -|-1.5|,\quad \left|\dfrac{-10}{3}\right|,\quad |-\sqrt{12}|
Values: 3.6,\ \ -4,\ \ 5,\ \ -1.5,\ \ 3.\overline{3},\ \ \sqrt{12}\approx3.46
\boldsymbol{-|4|\ <\ -|-1.5|\ <\ \left|\tfrac{-10}{3}\right|\ <\ |-\sqrt{12}|\ <\ |-3.6|\ <\ |2-7|}
Example 5

Compare, true or false

(a) Let a=-4 and b=6. Compare |a+b| with |a|+|b|, and |ab| with |a|\,|b|.
|a+b|=|2|=2, but |a|+|b|=4+6=10: not equal.
|ab|=|-24|=24 and |a|\,|b|=4\times6=24: equal.

(b) True or false? If true, explain; if false, give a counterexample.

(i) |3-10|=3-10
False: |3-10|=|-7|=7, but 3-10=-7.
(ii) |-2|\times|6|=|-12|
True: 2\times6=12 and |-12|=12.
(iii) |x|=x for every real number x
False: for x=-1, |-1|=1\ne-1.
(iv) |a-b|=|b-a| for all real a and b
True: a-b and b-a are opposites, and opposites have the same absolute value.

The Distance Between Two Numbers

On a number line, the distance between a and b is the absolute value of their difference. Subtracting in either order gives the same distance: from -3 to 5 is |5-(-3)|=|-3-5|=8 units.

Distance between a and b: |a-b|=|b-a|.   The numbers at a distance d from a are a+d and a-d.

Absolute value is used whenever only the size of a change or a difference matters, not its direction: a change in temperature, the number of floors an elevator travels, or how far a measurement is from its target.

Example 6

How far apart?

Determine the distance between the numbers. Give exact answers.

(a) 9 and 2
|9-2|=\boldsymbol{7}
(b) -6 and 4
|-6-4|=|-10|=\boldsymbol{10}
(c) -11 and -3
|-11-(-3)|=|-8|=\boldsymbol{8}
(d) -2.75 and 1.5
|-2.75-1.5|=|-4.25|
=\boldsymbol{4.25}
(e) \sqrt{2} and -\sqrt{8}
-\sqrt{8}=-2\sqrt{2}
|\sqrt{2}-(-2\sqrt{2})|=|3\sqrt{2}|=\boldsymbol{3\sqrt{2}}
(f) Which numbers are 4 units from -1?
-1+4=\boldsymbol{3} and -1-4=\boldsymbol{-5}
Example 7

Only the size matters

(a) The overnight low in Airdrie was -17\,^\circ\text{C} and the next afternoon’s high was 4\,^\circ\text{C}. By how many degrees did the temperature change?
|4-(-17)|=|21|=21, a change of 21 °C.
(b) An elevator starts on floor 14. Its next four trips are +7, -15, +4 and -9 floors (up is positive). On which floor does it finish, and how many floors does it travel in all?
Net change: 7-15+4-9=-13, so it finishes on floor 14-13=\boldsymbol{1}.
Total distance: |7|+|-15|+|4|+|-9|=7+15+4+9=\boldsymbol{35} floors.
(The net change keeps the signs; the total distance adds the absolute values.)
(c) A machine cuts bolts with a target length of 45.00 mm. A bolt of length L mm is accepted if |L-45.00|\le0.15. Which of these bolts are accepted: 44.82 mm, 45.09 mm, 45.15 mm, 45.21 mm?
|44.82-45.00|=0.18>0.15: rejected.   |45.09-45.00|=0.09: accepted.
|45.15-45.00|=0.15: accepted.   |45.21-45.00|=0.21: rejected.
The 45.09 mm and 45.15 mm bolts are accepted.

The Piecewise Definition

The distance idea gives an algebraic rule. A number that is positive or zero is its own absolute value. A negative number’s absolute value is its opposite: |-6|=-(-6)=6. Written in two pieces:

|x|=\begin{cases}\ \ x, & \text{if } x\ge0\\ -x, & \text{if } x<0\end{cases}In the second piece x is negative, so -x is positive.
For every real number x, \sqrt{x^2}=|x|.

In Unit 2 we wrote \sqrt{x^2}=x only after stating x\ge0; without that restriction, \sqrt{x^2}=|x|. The same definition works for an expression inside the bars: |x-4| is the distance between x and 4, and it equals x-4 when x-4\ge0 and -(x-4) when x-4<0. Lesson 2 does this for every expression ax+b.

Example 8

Using the definition

(a) Use the definition to evaluate |-3.8| and |2.4|.
-3.8<0, so |-3.8|=-(-3.8)=\boldsymbol{3.8}.
2.4\ge0, so |2.4|=\boldsymbol{2.4}.
(b) If x<0, simplify |x|+3x.
For x<0, |x|=-x.
|x|+3x=-x+3x=\boldsymbol{2x}
(c) Simplify \dfrac{|x|}{x} for x>0 and for x<0.
x>0: \dfrac{x}{x}=\boldsymbol{1}.   x<0: \dfrac{-x}{x}=\boldsymbol{-1}.
(x=0 is not allowed: division by zero.)
(d) Show that \sqrt{x^2}=|x| when x=-5, and explain why \sqrt{x^2}=x is false for x=-5.
\sqrt{(-5)^2}=\sqrt{25}=5 and |-5|=5.
A principal square root is never negative, so it cannot equal -5.
(e) Write |x-4| in piecewise form. Use it to evaluate |x-4| for x=10 and for x=1.
|x-4|=\begin{cases}x-4, & \text{if } x\ge4\\ -(x-4)=4-x, & \text{if } x<4\end{cases}
x=10\ge4: 10-4=\boldsymbol{6}.   x=1<4: 4-1=\boldsymbol{3}.  (Check: |6|=6, |-3|=3.)

Key ideas

Distance from 0. |a| is the distance from a to 0, so |a|\ge0, |-a|=|a| and |a|=\sqrt{a^2}. A sign outside the bars stays: -|6|=-6.
Bars are brackets. Simplify inside, take the absolute value, then finish. |ab|=|a|\,|b|, but |a+b|\ne|a|+|b| in general. To order, evaluate first; one counterexample shows a statement is false.
Distance between. |a-b|=|b-a|. The numbers d units from a are a\pm d. A net change keeps the signs; a total distance adds absolute values.
Piecewise. |x|=x if x\ge0, and |x|=-x if x<0 (then -x is positive). \sqrt{x^2}=|x| for every x.
